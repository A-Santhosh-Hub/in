# Cinematic chapter artwork

Generated with the built-in image-generation tool. The original photo `assets/San.png` is preserved. The portrait uses it as the identity reference and retains genuine alpha transparency.

## Files

Each chapter has a PNG master in `originals/`, a full-size WebP, and a `-mobile.webp` variant. The original PNGs remain available for future edits. The website loads responsive WebP files.

- `chapter-home`: opening hero / warm oceanfront.
- `chapter-work`: project chapter / neon district.
- `chapter-about`: creator chapter / rooftop studio.
- `chapter-contact`: contact chapter / twilight marina.
- `santhosh-character`: portrait in the opening and Big Ideas sections.

WebP encodings are generated by `node scripts/optimize-art.cjs` without retouching or cropping; alpha is retained. The image-generation skill supplied identity-preservation and transparent-cutout requirements.
